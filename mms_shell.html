各块数据从哪来、什么时候的
  • 券 / 会员：用友经理号当天全量拉取（券实例 + 剩余次数 + 员工归属），页面标的是真实拉取时刻。
  • 消费 / 九类 / 话术：用友零售单全量库 2026-01-01 起，每天按天增量追加并本地重算，标的是最新一张零售单日期。
  • 会员画像档案：全表扫描约 40 分钟，早上推群那份用的是上一轮扫描结果，本地文件随后更新。
  • 钢化膜核销：昨晚 22:51 的 raw，早上 08:00 当日 raw 尚未生成，属正常开盘口径。
  • 超过 3 天没更新的块会标红；任一环节拉取失败，顶部会出现红色告警并注明当前是旧数据。
员工名下会员待跟进累计跟进跟进率在账券剩余次数构成
这三个数字到底怎么算的
  • 名下会员：用友会员列表里归属该员工的全量在册人数，不等于有券的人数。
  • 待跟进：有在账券、且还没在客户页标记「已到店 / 已回访」的人数；标记后即时从待跟进里扣除。
  • 累计跟进 / 跟进率：已回访人数 ÷（已回访 + 待跟进），标记记录存在本机浏览器，不回写用友。
  • 在账券 / 剩余次数：当天用友券实例真实值；构成条按会员体系分组。
  • 店长监督视图列的是每位员工名下真实待跟进客户，点顶部「店长监督」查看。
